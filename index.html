Tips for layers

Drag layers into order, or use their arrow buttons. When selections overlap, a lower layer wins in the Mol* colour preview; the tracer still draws every matching layer.

One layer contains one component type: protein, nucleic acid, ligand, ion, or water. Select as many separate residues or molecules of that type as needed, but split different component types into separate layers.

Edit selection loads a layer into Mol*. Add or remove residues with the normal selection tools, then use the same button — now Save selection — to update the layer without changing its appearance.
